# Site artwork

The bin illustrations are page-specific CSS artwork. Jimothy is a generated illustration based on the raccoon reference supplied by Ivan, with his round silhouette, masked face and striped tail preserved. The illustration links to [Jimothy's background](https://en.wikipedia.org/wiki/Jimothy).

The production asset, `public/images/jimothy.webp`, has a transparent background and is encoded at 480 pixels wide for its 108–160 pixel display size. Explicit image dimensions reserve layout space. It is static, works on both Verdant themes and has descriptive alternative text. No original reference image or machine-local generation path is included in the repository.
